# لغة ضاد - بيئة البرمجة البصرية

<p align="center">
  <img src="assets/img/logo.svg" width="120" alt="شعار لغة ضاد">
</p>

**ضاد بلوكلي(Daad Blockly)** هي لغة برمجة عربية بالكامل.  
هذا التطبيق هو بيئة تطوير سطح مكتب تعتمد على **Blockly** من **Google** و **Electron**، تسمح لك بكتابة برامج بلغة ضاد عن طريق تركيب القطع البصرية (Blocks) دون الحاجة لكتابة الأكواد يدويًا.

> لا يحتاج التطبيق إلى خادم أو قاعدة بيانات — كل شيء يعمل محليًا على جهازك.

---

## المميزات

- **واجهة عربية كاملة** (RTL) بخطوط وألوان مريحة
- **أكثر من 40 قطعة برمجية** بصرية تغطي أساسيات البرمجة
- **توليد كود ضاد** تلقائيًا من القطع البصرية
- **تشغيل البرامج** مباشرة داخل التطبيق والتفاعل مع الإدخال (`ادخل`)
- **عرض المخرجات** بشكل فوري مع دعم الإدخال التفاعلي أثناء التشغيل
- **حفظ واسترجاع** مساحات العمل (ملفات JSON)
- **دعم Windows و Linux**
- **تصدير واستيراد** المشاريع عبر مربعات الحوار

---

## المتطلبات

- **Node.js** (الإصدار 18 أو أحدث)
- **نظام تشغيل:** Windows (x86-64) أو Linux (x86-64)

## كيفية الاستخدام

### 1. تركيب القطع

اسحب القطع من شريط الأدوات الجانبي إلى مساحة العمل. كل قطعة تولد كود ضاد تلقائيًا.

### 2. تشغيل البرنامج

انقر على زر **تشغيل** (يتحول إلى **إيقاف** أثناء التنفيذ). تظهر المخرجات مباشرة في لوحة المخرجات.

### 3. الإدخال التفاعلي

عند استخدام قطعة `ادخل`، يظهر حقل الإدخال تلقائيًا. اكتب النص ثم اضغط **إرسال**. يمكنك إرسال أكثر من قيمة أثناء التشغيل.

### 4. حفظ العمل

- **حفظ:** يحفظ تلقائيًا في مجلد المستخدم
- **حفظ باسم:** يفتح مربع حوار لحفظ الملف في مكان تختاره
- **فتح:** يفتح ملف مساحة عمل سابق

## القطع البرمجية

### النصوص

| القطعة     | الكود المولد  |
| ---------- | ------------- |
| نص         | `"..."`       |
| اطبع       | `اطبع(...)`   |
| طول النص   | `طول(...)`    |
| دمج النصوص | `... + ...`   |
| ألحق نص    | `س = س + ...` |
| حول إلى نص | `نص(...)`     |

### الأرقام

| القطعة        | الكود المولد   |
| ------------- | -------------- |
| عدد           | `رقم`          |
| عمليات حسابية | `(+ - * /)`    |
| أس            | `(... ** ...)` |
| باقي القسمة   | `(... % ...)`  |
| قسمة صحيحة    | `(... // ...)` |
| حول إلى عشري  | `عشري(...)`    |

### المنطق

| القطعة      | الكود المولد                 |
| ----------- | ---------------------------- |
| صحيح / خطأ  | `صحيح / خطأ`                 |
| مقارنة      | `(== != < <= > >=)`          |
| و / أو      | `(... و ...) / (... أو ...)` |
| نفي         | `ليس(...)`                   |
| معرفة النوع | `نوع(...)`                   |
| انتماء      | `(... في ...)`               |

### القوائم

| القطعة        | الكود المولد    |
| ------------- | --------------- |
| إنشاء قائمة   | `[ع1, ع2, ...]` |
| قائمة فارغة   | `[]`            |
| Tuple         | `(ع1, ع2, ...)` |
| عنصر من قائمة | `قائمة[رقم]`    |
| طول القائمة   | `طول(...)`      |

### القاموس

| القطعة | الكود المولد |
| ------ | ------------ |
| قاموس  | `{...}`      |

### العوامل

| القطعة     | الكود المولد                     |
| ---------- | -------------------------------- |
| تعيين مركب | `س +=, -=, *=, /=, %=, //=, **=` |
| عمليات بت  | `& , \| , ^ , << , >>`           |
| قلب البتات | `~...`                           |

### التحكم

| القطعة      | الكود المولد                  |
| ----------- | ----------------------------- |
| إذا / وإلا  | `اذا ... : واذا ... : والا :` |
| طالما       | `طالما ... :`                 |
| لكل         | `لكل ... في ... :`            |
| كرر         | `كرر ... مرات :`              |
| اخرج / تابع | `اخرج / تابع`                 |

### الدوال

| القطعة          | الكود المولد                |
| --------------- | --------------------------- |
| دالة بدون إرجاع | `دالة اسم(وسائط):`          |
| دالة مع إرجاع   | `دالة اسم(وسائط): ... ارجع` |
| إرجاع شرطي      | `اذا ... : ارجع`            |
| استدعاء دالة    | `اسم(وسائط)`                |

### المتغيرات

| القطعة | الكود المولد  |
| ------ | ------------- |
| متغير  | `اسم_المتغير` |
| تعيين  | `اسم = ...`   |

### دوال مدمجة

| القطعة     | الكود المولد        |
| ---------- | ------------------- |
| إدخال      | `ادخل(...)`         |
| استيراد    | `استورد ...`        |
| استيراد من | `من ... استورد ...` |

### الكائنات

| القطعة             | الكود المولد             |
| ------------------ | ------------------------ |
| صنف                | `صنف اسم:`               |
| دالة (خاصة بالصنف) | `دالة اسم(ذاتي, وسائط):` |
| ذاتي               | `ذاتي`                   |
| خاصية              | `كائن.خاصية`             |
| تعيين خاصية        | `كائن.خاصية = ...`       |
| إنشاء كائن         | `اسم(وسائط)`             |

## مثال: برنامج ترحيب

```python
# كود ضاد مولّد من القطع البصرية
اطبع("مرحباً بك في لغة ضاد!")
الاسم = ادخل("ما اسمك؟ ")
اطبع("أهلاً، " + الاسم)
```

**خطوات بناء البرنامج:**

1. اسحب قطعة **اطبع** من قسم النصوص واكتب النص
2. اسحب قطعة **إدخال** من قسم الدوال المدمجة وأدخل رسالة التنبيه
3. اسحب قطعة **متغير** من قسم المتغيرات وسمّه `الاسم`
4. وصّل قطعة الإدخال إلى المتغير
5. اسحب قطعة **اطبع** أخرى وألحق بها اسم المتغير

---

## مثال: صنف (برمجة كائنية)

```python
صنف شخص:
  دالة __init__(ذاتي, اسم, عمر):
    ذاتي.اسم = اسم
    ذاتي.عمر = عمر

  دالة تقديم(ذاتي):
    اطبع("أنا " + ذاتي.اسم + "، عمري " + نص(ذاتي.عمر) + " سنة")

الموظف = شخص("سامر", 25)
الموظف.تقديم()
```

## مثال: لعبة تخمين الرقم

```python
استورد random
الرقم_السري = random.randint(1, 10)
المحاولات = 3

طالما المحاولات > 0:
  التخمين = عشري(ادخل("خمن رقماً بين 1 و 10: "))
  اذا التخمين == الرقم_السري:
    اطبع("أحسنت! لقد فزت")
    اخرج
  والا:
    المحاولات = المحاولات - 1
    اطبع("خطأ! تبقى لديك " + نص(المحاولات) + " محاولات")

اطبع("الرقم السري كان: " + نص(الرقم_السري))
```
